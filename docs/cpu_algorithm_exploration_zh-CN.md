# V.35 CPU 采样沿算法探索结论

文档修订：v1.0
对应 RTL 基线：v1.0（未修改）
状态：参考模型探索阶段冻结，等待真实测量数据
日期：2026-08-20

## 1. 目的与边界

本文档记录历史 CPU 判决算法的重建、可执行参考模型、已发现的失效模式以及候选增强方案。它不声称候选算法已经用于原产品，也不把探索门限写成产品要求。

## 2. 已建立事实

1. CPLD 每次事务产生一个 `phase_count`；多样本统计属于 CPU 软件。
2. 上电或频率变化后，原 CPU 收集 10 个有效结果并计算普通算术平均。
3. 运行期每隔约 1 s 取得一个结果，当前按三个非重叠结果形成一批、约每 3 s 裁定一次进行重建。
4. 首次和持续裁定使用历史资料中的区间表；持续表具有保持区。
5. 当前 CPLD RTL v1.0 不需要为算法探索修改。

## 3. 原算法的适用范围

普通算术平均在样本形成稳定、单峰且不跨越 `0/T` 的分布时，与圆周平均产生相同裁定。原算法并非普遍错误，其主要局限出现在相位量的圆周属性和异常分布上。

## 4. 已复现的失效模式

### 4.1 相位回绕

当样本聚集在周期首尾两侧时，普通平均会把它们拉到周期中部。定向场景中，普通平均为 `48.20`，圆周平均约为 `0.20`；两者分别选择上升沿和下降沿。圆周集中度为 `0.997`，说明该分布稳定，并非随机噪声。

### 4.2 分散和双峰

- 全周期宽分布的圆周集中度为 0，圆周均值无定义；
- 相隔半周期的双峰分布虽然可能产生一个数值均值，但集中度接近 0，均值不具有代表性。

### 4.3 单个远端样本

一个远端样本可能把普通平均推过判决边界。圆周平均不等于通用异常值过滤器；此类场景更适合由低集中度触发拒绝裁定或追加测量。

### 4.4 稳定但贴近边界

高集中度只说明测量位置稳定。若圆周均值接近有效决策边界，采样沿选择仍缺少裕量。因此稳定度和决策裕量必须独立判断。

## 5. 两个置信指标

- 圆周集中度：描述相位样本是否在圆周上聚集，范围为 0 至 1；
- 归一化圆周决策裕量：圆周均值到最近“最终采样沿会改变”的有效边界的距离除以周期 `T`。

`0/T` 只是数值回绕点，不是首次校准的决策边界。持续校准具有保持区，因此有效边界取决于当前采样沿。

## 6. 候选增强控制策略

参考增强按以下顺序处理：

1. 用圆周统计计算平均相位和集中度；
2. 若圆周均值无定义或集中度不足，拒绝本轮裁定；
3. 计算归一化圆周决策裕量；
4. 若裕量不足，拒绝本轮裁定；
5. 通过置信门后，把圆周均值代入历史区间表；
6. 首次校准拒绝时不发布新采样沿并请求重测；
7. 运行期拒绝时保持当前采样沿。

当前程序以“集中度不低于 0.9、圆周裕量/T 不低于 0.025”演示系统行为。该组合只是定向场景中的观察点，不是冻结门限。

## 7. 动态响应结果

按每秒一个有效结果、三个结果形成一批估算：

| 场景 | 原算法 | 候选增强 |
|---|---|---|
| 缓慢跨越切换边界 | 第 4 批切换 | 第 6 批切换，约增加 6 s |
| 快速明确跳变 | 第 2 批切换 | 第 2 批切换，无额外延迟 |
| 噪声跨越 | 第 3 批切换 | 第 7 批切换，约增加 12 s |
| 短暂越界后退回 | 切换后因保持区不自动恢复 | 不切换 |

置信门的价值是避免低证据切换，代价是对缓慢真实漂移增加响应延迟。没有产品允许的最大切换延迟和误切换代价，不能确定最终门限。

## 8. 阶段性裁决

[已确认]

- 原算法的普通平均不能正确处理 `0/T` 回绕；
- 集中度和决策裕量分别描述统计可信度与裁定明确度，不能互相替代；
- 持续表中的保持区确实抑制反复切换，但也可能使短暂越界造成的切换长期保留；
- 候选增强不要求修改 CPLD v1.0 RTL。

[候选方案]

- CPU 使用圆周平均、集中度门和归一化裕量门；
- 首次拒绝后重测，运行期拒绝后保持当前沿。

[尚未确认]

- 真实设备的相位分布是否会跨回绕、形成双峰或包含远端样本；
- 集中度与裕量的产品门限；
- 首次校准允许重试多少次，以及失败后的默认采样沿和故障上报；
- 运行期允许的最大切换延迟；
- 频率变化检测与重新校准入口；
- CPU 写入 TDMoP 的真实控制路径。

## 9. 冻结条件与恢复条件

当前算法探索冻结，不继续增加统计复杂度。只有获得以下任一输入后再恢复：

1. 真实板上连续 `phase_count` 日志；
2. 产品允许的误切换率、最大响应时间或校准失败策略；
3. 原 CPU 源码或更完整的软件需求；
4. 板级测试证明现有判决在特定频点仍产生误码。
