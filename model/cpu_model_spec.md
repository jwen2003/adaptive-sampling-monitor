# CPU 采样沿裁定参考模型

本目录实现历史 CPU 算法的最小可执行参考版本，不属于 CPLD RTL。

## 已实现语义

- 上电或变频后收集 10 个有效相位结果，使用普通算术平均执行首次裁定；
- 首次裁定完成后，由调用方每隔 1 s 提供一个有效结果；
- 每 3 个结果形成一个非重叠批次，裁定后清空批次；
- 持续裁定表中的保持区、原文空窗和精确阈值均保持当前采样沿；
- 首次裁定表的精确阈值没有历史定义，模型显式报告 `unresolved_initial_boundary`；
- 变频事件丢弃未完成批次并重新进入 10 样本首次校准；
- 使用有理数进行平均与阈值比较，避免浮点舍入改变边界归属。

## 刻意没有实现

- 真实 1 s 定时器；
- CPLD 寄存器轮询和读清；
- 频率变化检测；
- TDMoP 寄存器写入；
- 圆周平均、异常值过滤、置信度或自动失败恢复。

这些功能目前不是缺失代码，而是尚未冻结的系统行为。

## 运行测试

在仓库根目录执行：

```bash
python -m unittest discover -s model -p 'test_*.py' -v
```

运行算法场景对照：

```bash
python model/compare_decision_algorithms.py
```

运行候选门限扫描：

```bash
python model/scan_decision_thresholds.py
```

扫描结果写入 `threshold_scan_results.md`。默认枚举多组最小集中度和最小归一化圆周裕量，只显示各参数组合接受或拒绝哪些定向场景，不自动选择产品门限。

运行带置信门的最终动作模拟：

```bash
python model/simulate_guarded_controller.py
```

默认仅用集中度 $\ge 0.9$、圆周裕量与 $T$ 的比值 $\ge 0.025$ 展示系统行为。首次校准拒绝时输出 `recalibrate`，不发布新采样沿；运行期拒绝时保持当前沿。该默认值来自当前定向场景的观察分界，不是产品定值。

运行动态相位跟踪：

```bash
python model/simulate_dynamic_tracking.py
```

动态场景定义在 `dynamic_phase_scenarios.json`，结果写入 `dynamic_tracking_results.md`。当前按每秒一个有效结果、三个结果形成一个非重叠批次，将一个决策批次估算为 3 秒；该换算仍受原调度语义重建假设约束。

场景定义保存在 `algorithm_scenarios.json`，生成结果写入
`algorithm_comparison_results.md`。前者可以替换或追加真实测量序列。

对照场景同时报告普通平均与圆周平均各自到最近有效决策边界的距离，并给出除以 $T$ 后的归一化裕量。裕量只回答“对应均值离切换边界多远”，不能证明均值本身具有物理代表性；圆周集中度另外回答样本是否聚集。$0/T$ 只是相位表示的回绕点，其两侧都选择下降沿，因此不计作首次校准的决策边界。持续校准存在保持区，有效决策边界取决于当前采样沿。连续运行期场景还报告各批次最终采样沿和实际切换次数。

回绕测试刻意证明原算法的局限：当样本同时聚集在 `0` 和 $T$ 两侧时，普通算术平均可能落到周期中部，进而给出与物理聚类位置不一致的裁定。该测试不是要求当前参考模型修正原算法。
